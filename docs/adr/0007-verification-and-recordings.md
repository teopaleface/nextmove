# Functional evidence is part of delivery

The local application is delivered with proportionate unit/integration checks for financial and authority invariants plus rendered end-to-end verification on a phone viewport and a wider host. Every accepted capability receives a truthful evidence level and runnable test/scenario; core flows include merchant browser execution, changed terms, partial batches, response loss, restart recovery, cross-session denial and refund accounting.

Record each implemented functional area through actual UI interactions, preferably T3 collaborative browser recording; use headless test-run recordings where bulk reproducibility is useful. Keep recordings local and generated runtime/secret data outside Git; commit an evidence index with scenario/build/results and reproducible commands. Videos supplement assertions and do not certify production security, legal compliance or third-party coverage.
