# Controlled simulation first; future product inside a partner bank

We implement a fictional mobile bank and controlled merchant systems using synthetic accounts, money, contracts and documents. Real model calls, calculations, browser interactions and state transitions run locally; real bank credentials, payment rails and third-party contractual writes remain outside this environment. This makes the full workflow demonstrable while the chosen commercial route—a feature embedded in a partner bank—receives its own legal, privacy, security and integration validation.

An arbitrary consumer browser robot would broaden access and contractual risks without proving a bank integration. Supported merchant workflows therefore have explicit capabilities and verification rules; unsupported cases remain visible manual tasks.
