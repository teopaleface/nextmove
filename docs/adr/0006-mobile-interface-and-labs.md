# Phone-first banking hierarchy and server-enforced experimental access

Use the supplied NextMove tokens, mockups and 28 screen templates with four stable destinations: Home, Activity, Goals and Agent. Personal/business contexts share financial interfaces while keeping funds, authority and records distinct; the interface and pitch use English.

Labs permits implemented experimental workflows only against isolated fictional resources. Availability is enforced on the server and worker by feature, environment, integration, authority and current validation status. Geography/IP alone does not establish safety or regulatory scope. All modes retain the same basic data isolation, secret protection and approval rules; a grey button or a Labs label does not authorize real writes.
