# Deterministic financial calculations and evidence-based accounting

Code owns bounded integer minor units, currency, dated event order, comparison windows, reserves and formulas. Model output chooses tools and explains their returned calculations; it cannot edit balances or substitute invented financial results. Unknown inputs stay unknown, and factual corrections create new revisions.

Keep avoided future charges, conditional estimates, accepted refund claims and unique posted bank credits separate. The single-trial UI case is 242 → 163 RON upcoming with 110,000 RON unchanged funds; the independent 200-item stress fixture has 100 expected confirmations and 2,824 RON avoided charges. Do not combine those datasets or annualize their one-window savings.
